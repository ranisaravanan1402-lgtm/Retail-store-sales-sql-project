# SQL projects
This project analyzes retail store sales data using SQL to identify sales trends, customer purchasing patterns, product performance, and overall business performance. The project includes SQL queries for calculating important business metrics such as total orders, total revenue, average order value, highest sale and most popular payment mode.

Total revenue
Average order value
Highest sale
Gross amount before discount
Product-wise sales and quantity
City-wise sales
Payment-mode analysis
Top-selling products

Highest-performing cities
Top 5 highest-value transactions

Objective: To transform raw retail sales data into meaningful business insights using SQL and demonstrate practical SQL data-analysis skills.
